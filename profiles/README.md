# Role-family positioning

Each role profile selects high-relevance evidence from the career master. It does not change underlying facts.

Potential profiles:
- `macro_scenarios.md` — macro risk, scenarios, stress testing, time-series analysis.
- `equity_quant.md` — systematic equities, signal testing, portfolio relevance.
- `banking_risk_policy.md` — bank-sector risk, supervision/regulation, emerging risks.
- `ai_fintech.md` — AI adoption, governance, financial sector impact.
- `thematic_investment.md` — industry structure, catalysts, valuation implications.

For each profile store: target job titles, role requirements, evidence IDs, priority order, CV narrative, keyword vocabulary, and prohibited overclaims.
