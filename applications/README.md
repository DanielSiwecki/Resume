# Application records

Once this repository is private, retain one folder per application, e.g. `YYYY-MM-DD_employer_role/`.

Recommended contents:
- `job_description.md`
- `cv.tex` and `cv.pdf`
- `cover_letter.tex` and `cover_letter.pdf` (if applicable)
- `metadata.yaml` with submission date, fit rationale, core evidence IDs, application status and outcome.

Keep job postings and application outcomes separate from the verified experience master. Never treat an application's rhetoric as a source of new facts.
