# Career knowledge base

This repository is being expanded from an archive of CVs into a structured source of truth for tailored applications.

## Structure
- `archive/` — historical CVs and cover letters, preserved verbatim with date/role metadata.
- `master/` — source-backed career history, project evidence, skills, publications, and quantified outcomes.
- `profiles/` — role-family positioning strategies that select, never invent, evidence.
- `templates/` — reusable editable CV and cover-letter layouts.
- `applications/` — role descriptions, submitted versions, outcomes and feedback.
- `guidance/` — factual and editorial rules.

## Safety gate
**Do not upload further CVs, personal contact details, application histories, or the populated career master until this repository is private.** Confirm visibility in GitHub Settings. Changing visibility will not undo any historical public exposure.

## Application workflow
1. Save the job description and note required competencies.
2. Retrieve evidence from the master and archive.
3. Select strongest verifiable examples and an appropriate template.
4. Draft role-specific bullets without adding unsupported claims.
5. Validate dates, titles, roles, metrics, methods and claims.
6. Generate a submission PDF and preserve the exact source/outputs.
7. Log the application stage and later outcome.

Any data conflicts or unverified metrics must be flagged rather than silently reconciled.
