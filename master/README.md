# Verified experience and evidence

The `master/` directory will contain source-backed career facts and achievement records. Each evidence item should identify:
- role, organization, project and date;
- exact action, method, scope, outcome and audience;
- evidence source (e.g., source CV path, public publication, employer record);
- confidence: `confirmed`, `candidate`, `needs_review`, or `historical`;
- restrictions on wording, confidentiality and attribution;
- relevance tags for role targeting.

Historical CV assertions are **not automatically verified**. Conflicting dates, role titles, sample sizes or outcomes should be retained as issues for review.
See `achievement_schema.yaml` for the proposed record format.
